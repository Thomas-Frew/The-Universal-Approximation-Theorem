# Launch Party

Thanks to everyone who helped with the initial test of The Universal Approximation Theorem! We have implemented the following changes:

- Java 25 is now one of the languages, alongside Python, C++ and Go. Your class must be called `Main`. The guide's examples for reading input now include Java too.

- When your code crashes during a Run, the table says why, and for Python, Go and Java on which line. That line is marked in the editor.

- The editor opens in the language you chose last.

- Machines after the first start from an empty `main`.

- Run and Submit are turned off while the editor is empty.

- The Tab key works as in most code editors (like VS Code).

- New players see a banner on each machine pointing to the guide, until they open the guide or dismiss the banner.

- Stats is now a button on every page.

- The stats page has a new board of first solvers: who solved the most machines before anyone else.

- You can rename yourself from the scoreboard.

- You now stay signed in for a year between visits, rather than a week.

- On mobile, the buttons at the top of each page have a row of their own, so they no longer cover the page's name.
