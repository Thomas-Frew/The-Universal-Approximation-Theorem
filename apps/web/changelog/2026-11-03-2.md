# Solvers per Machine

- The stats page has a new table, Solvers per Machine: pick a machine to see everyone who has solved it, sorted by penalty, time taken, or who solved it first.

- New players are asked what to call them before the first machine, with their save key and a way to load an old one on the same page.

- The button at the top of the stats page now says Back, since it returns to wherever you came from.

- The Credits page (Settings → Credits) now says who the game is dedicated to, and why.

- Links to the game now show the owl in their previews on Discord and elsewhere.
